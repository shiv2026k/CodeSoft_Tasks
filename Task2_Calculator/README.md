# Task 2: Basic Arithmetic Calculator

### Project Description
This project features a clean and interactive user-driven calculator designed using core Python programming concepts. It allows users to execute standard mathematical operations seamlessly through a straightforward and highly intuitive command-line prompt interface.

### Key Features
- **User-Input Prompts:** Accepts two numerical inputs from the user consecutively.
- **Addition Operation:** Computes the total sum of the two entered numbers.
- **Subtraction Operation:** Subtracts the second input value from the first input value.
- **Multiplication Operation:** Multiplies both user-entered numerical values instantly.
- **Division Handling:** Safely performs division of the first number by the second number.
- **Zero Error Prevention:** Incorporates built-in logic to avoid crash during division by zero.
- **Clear Display:** Shows the complete equation along with the calculated result on screen.

### How to Run
1. Ensure you have Python installed and set up in your system environment.
2. Launch your command prompt/terminal and open the directory containing the file.
3. Execute the script with the following command: `python calculator.py`.
4. Input your numbers, choose an operator, and see the immediate output.

# CodSoft Python Programming Internship Tasks

Welcome to my GitHub repository for the **CodSoft Python Programming Internship**! This repository serves as a centralized hub containing all the practical projects developed during my virtual internship journey. The main goal of these tasks is to transform core theoretical knowledge into functional, real-world software applications.

---

## 🚀 Repository Structure Overview

Each folder or file in this repository corresponds to a specific technical milestone assigned by CodSoft. Below is the detailed breakdown of all individual projects:

## 📝 Task 1: To-Do List Application
- **Description:** A comprehensive tool designed to help users manage, track, and organize daily tasks efficiently. 
- **Key Features:** Supports creating new tasks, viewing active lists, updating existing entries, tracking completion status, and deleting unwanted records.
- **Interface:** Command-Line Interface (CLI) / Graphical User Interface (GUI).

## 🧮 Task 2: Simple Calculator
- **Description:** A user-friendly digital calculator developed to execute foundational mathematical calculations seamlessly.
- **Key Features:** Prompts for two numerical inputs, performs basic arithmetic operations (Addition, Subtraction, Multiplication, Division), and includes robust validation to prevent division-by-zero errors.

## 🔐 Task 3: Password Generator Tool
- **Description:** A highly secure utility application crafted to generate strong, complex, and completely random passwords.
- **Key Features:** Custom length specifications, strict combination of uppercase/lowercase alphabets, digits, and special characters, built using secure Python libraries.

## 🎮 Task 4: Rock-Paper-Scissors Game
- **Description:** An interactive digital recreation of the traditional hand game played against an automated computer AI.
- **Key Features:** Randomized computer intelligence selection, real-time score tracking system for multiple rounds, tie-detection logic, and an instant replay choice option.

## 📞 Task 5: Contact Book Management System
- **Description:** A personal database manager designed to save and handle crucial communication credentials securely.
- **Key Features:** Detailed data collection (Name, Phone, Email, Address), seamless search functionality, instant record updates, and clean database deletion options.

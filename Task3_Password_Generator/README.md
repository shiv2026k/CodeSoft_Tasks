# Task 3: Random Password Generator Tool

### Project Description
Security is paramount, and this Python application acts as a utility tool to generate strong, secure, and completely randomized passwords. It helps users protect their online accounts by generating unpredictable keys based on customized length preferences.

### Key Features
- **Custom Length Input:** Promptly asks the user to define the exact length of the password.
- **High Complexity:** Utilizes a rich mix of characters to ensure high-grade password security.
- **Uppercase & Lowercase:** Combines both capital letters and small alphabets randomly.
- **Digits & Symbols:** Includes numbers and special characters to maximize password strength.
- **Secrets Module:** Built using secure Python libraries to ensure maximum unpredictability.
- **Instant Display:** Instantly outputs the newly minted secure password onto the console screen.
- **Error Handling:** Validates user inputs to ensure the entered length is a positive integer.

### How to Run
1. Open any terminal or command prompt window on your personal computer.
2. Navigate directly to the folder where the script file is currently stored.
3. Run the password script using this command: `python password_gen.py`.
4. Type your desired character count and press enter to generate your password.

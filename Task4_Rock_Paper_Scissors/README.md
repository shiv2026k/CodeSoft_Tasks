# Task 4: Interactive Rock-Paper-Scissors Game

### Project Description
This is a fun and interactive digital version of the classic Rock-Paper-Scissors game built using Python. Users can play multiple rounds against an automated computer opponent, featuring real-time game logic, score tracking, and smooth interactive feedback loop.

### Key Features
- **User Selection:** Promptly asks the player to select Rock, Paper, or Scissors.
- **AI Computer Selection:** Uses a randomized algorithm to pick the computer's secret move.
- **Advanced Game Logic:** Evaluates choices based on standard rules (Rock beats Scissors, etc.).
- **Tie Detection:** Checks and announces if both the player and computer picked the same move.
- **Live Score Tracking:** Maintains a running score for both the human player and computer.
- **Play Again Loop:** Prompts the user at the end of each round if they want to play again.
- **Robust Validation:** Safely handles invalid user textual choices without crashing the game.

### How to Run
1. Open the project folder inside your system terminal or command line interface.
2. Initiate the game by running the following command: `python rps_game.py`.
3. Type your choice exactly as instructed on the command line screen.
4. View results instantly and decide whether to continue playing more rounds.

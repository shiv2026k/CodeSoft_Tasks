# Task 5: Digital Contact Book Management System

### Project Description
This Python project functions as a personal Database Management system for storing and managing contact information. It provides an efficient platform to store essential communication details safely and perform basic CRUD operations via an intuitive interface.

### Key Features
- **Detailed Data Storage:** Saves full names, phone numbers, email addresses, and home addresses.
- **Add Contacts:** Allows seamless creation and addition of new contact entries to the book.
- **View Contact List:** Displays a complete, cleanly structured directory of all saved records.
- **Smart Search Function:** Users can quickly find any contact by searching names or phone numbers.
- **Update Records:** Provides a quick method to modify existing phone numbers or addresses.
- **Delete Functionality:** Allows users to remove obsolete or unwanted contacts from the system database.
- **Persistent Interface:** Keeps running on a logical loop until the user chooses to exit.

### How to Run
1. Navigate to the contact book project folder through your command terminal.
2. Execute the python file using the following command line: `python contact_book.py`.
3. Choose your desired action from the displayed numerical dashboard menu.
4. Input the requested details to successfully manage your digital contact dictionary.
